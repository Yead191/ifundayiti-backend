--------------------------------------------------------------------------------
A. COMMUNITY POSTS API ENDPOINTS
--------------------------------------------------------------------------------

1. CREATE COMMUNITY POST (Admin Only)
   - Method: `POST`
   - URL: `/api/v1/community`
   - Auth: Bearer Token (Role: `SUPER_ADMIN`, `ADMIN`)
   - Headers:
     - `Content-Type: multipart/form-data` OR `application/json`
   - Body (JSON):
     ```json
     {
       "title": "Welcome to the Official iFundAyiti Community Discussion",
       "content": "We are thrilled to launch the community forum. All members can interact...",
       "images": [
         "https://res.cloudinary.com/demo/image/upload/announcement.jpg"
       ],
       "isPinned": true,
       "isLocked": false,
       "status": "published"
     }
     ```
   - Body (Multipart Form-Data):
     - `data`: JSON string of `{ "title": "...", "content": "...", "isPinned": true }`
     - `images`: One or more image files (uploaded automatically to disk/cloud).
   - Side Effects:
     - Sends in-app socket notification to ALL users (`path: '/community/:id'`).
     - Sends branded HTML email notification to all active verified users.
   - Response: `201 Created`
     ```json
     {
       "statusCode": 201,
       "success": true,
       "message": "Community post created and broadcasted successfully",
       "data": {
         "_id": "67a3f890ce611ddc22e60531",
         "title": "Welcome to the Official iFundAyiti Community Forum",
         "content": "We are thrilled to launch the community forum...",
         "images": [],
         "author": {
           "_id": "679c1234567890abcdef1234",
           "name": "Administrator",
           "email": "admin@ifundayiti.com",
           "image": "https://...",
           "role": "SUPER_ADMIN"
         },
         "isPinned": true,
         "isLocked": false,
         "status": "published",
         "totalLikes": 0,
         "totalComments": 0,
         "createdAt": "2026-09-22T03:30:00.000Z",
         "updatedAt": "2026-09-22T03:30:00.000Z"
       }
     }
     ```

2. GET ALL COMMUNITY POSTS (Public / Member Feed)
   - Method: `GET`
   - URL: `/api/v1/community`
   - Auth: Optional (Send Bearer Token if logged in to get personalized `isLikeByMe`)
   - Query Parameters:
     - `searchTerm`: string (searches title & content)
     - `page`: number (default: 1)
     - `limit`: number (default: 10)
     - `isPinned`: boolean (`true` or `false`)
     - `isLocked`: boolean (`true` or `false`)
     - `status`: `'published'` | `'draft'` | `'archived'` (admins can filter drafts; defaults to published for public)
     - `sortBy`: string (default: `isPinned: -1, createdAt: -1`)
   - Response: `200 OK`

PART 6: KEY DIFFERENCES FROM LEGACY HUBOLOGY IMPLEMENTATION
================================================================================
1. **Posting Permission**:
   - Legacy: Any registered user could post.
   - Now: ONLY `SUPER_ADMIN` and `ADMIN` can publish posts (`403 Forbidden` for regular users).
2. **Community Notifications**:
   - Every published announcement sends simultaneous in-app notifications AND branded emails to all verified members.
3. **Category Removed**:
   - Forum no longer uses the rigid `category` filter or `COMMUNITY_CATEGORY` enum.
4. **Reports & Report Count Removed**:
   - No `reportCount` or legacy `Report` model. Admins directly curate and moderate discussions from the dashboard.
5. **Like & Comment Architecture**:
   - Stored in separate collections: `community_likes`, `community_comments`, and `community_comment_likes`.
   - Native support for nested comment replies (`parentComment`) and comment likes.
