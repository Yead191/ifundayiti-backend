================================================================================
EXECUTIVE SUMMARY: WHAT WAS FIXED & ENHANCED
================================================================================
1. **Deletion Capabilities Added**:
   - `DELETE /donation/:id` — Safely deletes a single donation or grant transaction record from database history and automatically synchronizes the `ProgramFund` balance.
   - `DELETE /donation/delete-multiple` — Supports batch selecting rows on the admin dashboard and deleting multiple transaction records simultaneously.
2. **Detailed Transaction Fetch Added**:
   - `GET /donation/:id` — Enables admin to open an in-depth Transaction Detail Drawer/Modal with populated applicant information, project title, and grant period.
3. **Optimized Search & Sorting**:
   - Added database indexes on `createdAt: -1`, `type: 1`, `email: 1`, and `transactionId: 1`.
   - Default sorting defaults to newest first (`-createdAt`).
   - Cleaned up search fields to match actual schema root attributes (`name`, `email`, `transactionId`).
4. **Enriched Fund Stats (`GET /donation/fund-stats`)**:
   - Now returns not only `balance`, `totalDonations`, and `totalGrants`, but also `donationCount`, `grantCount`, `totalCount`, and `programFundBalance`.
5. **Cleaned Up Unused Parameters**:
   - Removed obsolete hardcoded local IP address (`10.10.26.173`) from controller arguments.

```markdown
### TASK: Build Premium Donations & Fund Management in Admin Dashboard

Implement a high-end, financial-grade Fund Transactions & Donations Management section in the Admin Dashboard (`/admin/donations` or `/admin/fund-transactions`).

---

#### 1. FUND OVERVIEW & STATS WIDGETS
- Fetch fund statistics using `GET /donation/fund-stats`.
- Render 4 top-tier GlassCard metric widgets with Ant Design icons and subtle border gradients:
  - **Net Available Fund Balance**:
    - Value: `$balance` (formatted as currency: `$XX,XXX.XX`).
    - Subtitle: Current liquidity available for disbursement.
    - Icon: `WalletOutlined` (Emerald theme).
  - **Total Donations Received**:
    - Value: `$totalDonations` (formatted as `$XX,XXX.XX`).
    - Subtitle: `${donationCount} contributions from global donors`.
    - Icon: `RiseOutlined` (Sky blue / Teal theme).
  - **Total Grants Disbursed**:
    - Value: `$totalGrants` (formatted as `$XX,XXX.XX`).
    - Subtitle: `${grantCount} grants awarded to local projects`.
    - Icon: `GiftOutlined` (Amber theme).
  - **Total Transaction Volume**:
    - Value: `${totalCount} records`.
    - Subtitle: Combined donation inflows and grant outflows.
    - Icon: `SwapOutlined` (Indigo theme).

---

#### 2. TRANSACTIONS DATA TABLE & FILTERS
- Fetch transactions using `GET /donation` (supports pagination, search, and type filters).
- **Toolbar & Filter Controls**:
  - **Search Input**: Real-time debounced search by donor name, email, or Stripe transaction ID.
  - **Type Tabs / Segmented Control**:
    - `All Transactions`
    - `Donations Inflow` (filters `?type=donation`)
    - `Grants Outflow` (filters `?type=grant`)
  - **Batch Delete Button** (appears when rows are selected):
    - Shows `Delete Selected (${count})`.
    - Triggers confirmation modal and calls `DELETE /donation/delete-multiple` with `{ "ids": string[] }`.
  - **Refresh Button & Export CSV Action**.

- **Table Columns**:
  1. **Transaction ID / Reference**:
     - Monospace code chip (e.g. `cs_live_...` or `cs_test_...`).
     - Copy button on hover.
  2. **Type**:
     - `Donation`: Emerald pill tag (`+ $Amount`, with `ArrowDownLeftOutlined` icon).
     - `Grant`: Amber pill tag (`- $Amount`, with `ArrowUpRightOutlined` icon).
  3. **Donor / Recipient**:
     - If Donation: Donor Name & Email.
     - If Grant: Admin name or Applicant Project Title (from populated `applicant.personal` and `applicant.projectTitle`).
  4. **Amount**:
     - Bold styled currency (`+$50.00` in green for donations, `-$500.00` in amber for grants).
  5. **Date & Time**:
     - Formatted creation date (e.g., "Sep 14, 2026 • 11:15 AM").
  6. **Actions**:
     - **View Details**: Opens Transaction Detail Drawer (`GET /donation/:id`).
     - **Delete**: Prompts warning modal:
       *"Are you sure you want to delete this donation record? This will purge the record from transaction history and synchronize fund balance calculations."*
       Calls `DELETE /donation/:id`.

---

#### 3. TRANSACTION DETAIL DRAWER (`GET /donation/:id`)
- Slide-out side drawer displaying full receipt / audit details:
  - Large amount header with status badge.
  - Stripe Checkout Session ID / Transaction Reference.
  - Donor Information: Name, Email address, Timestamp.
  - If Grant: Awarded Applicant Name, Project Title, Success Story Quote, and Application Period title.
  - Action buttons: "Print Receipt / PDF", "Delete Record".
```

BASE URL:
  - http://localhost:5000/api/v1 (or production base URL)
  - `/donation` (or `/donations`)

--------------------------------------------------------------------------------
1. GET ALL DONATIONS & GRANTS
--------------------------------------------------------------------------------
- Method: GET /donation
- Access: ADMIN, SUPER_ADMIN
- Query Parameters:
  - `page`: number (default: 1)
  - `limit`: number (default: 10)
  - `searchTerm`: string (searches `name`, `email`, `transactionId`)
  - `type`: "donation" | "grant" (filter by transaction type)
  - `sort`: string (default: "-createdAt")

2. GET FUND STATISTICS
--------------------------------------------------------------------------------
- Method: GET /donation/fund-stats
- Access: ADMIN, SUPER_ADMIN
- Response (200 OK):
  ```json
  {
    "statusCode": 200,
    "success": true,
    "message": "Fund stats fetched successfully",
    "data": {
      "balance": 14500,
      "programFundBalance": 14500,
      "totalDonations": 24500,
  ```

--------------------------------------------------------------------------------
3. GET SINGLE DONATION DETAILS
--------------------------------------------------------------------------------
- Method: GET /donation/:id
- Access: ADMIN, SUPER_ADMIN
- Response (200 OK): Returns populated transaction details including applicant & period info.

--------------------------------------------------------------------------------
4. CREATE DONATION (STRIPE CHECKOUT)
--------------------------------------------------------------------------------
- Method: POST /donation
- Access: Public
- Headers: `Content-Type: application/json`
- Request Body:
  ```json
  {
    "name": "John Doe",
    "email": "john@example.com",
    "amount": 50
  }
  ```
- Response (201 Created):
  ```json
  {
    "statusCode": 201,
    "success": true,
    "message": "Donation checkout session created",
    "data": {
      "paymentUrl": "https://checkout.stripe.com/c/pay/cs_test_..."
    }
  }
  ```

--------------------------------------------------------------------------------
5. DELETE SINGLE DONATION RECORD
--------------------------------------------------------------------------------
- Method: DELETE /donation/:id
- Access: ADMIN, SUPER_ADMIN
- Response (200 OK):
  ```json
  {
    "statusCode": 200,
    "success": true,
    "message": "Donation record deleted successfully",
    "data": { ...deletedDonationObject }
  }
  ```

--------------------------------------------------------------------------------
6. BATCH DELETE MULTIPLE DONATION RECORDS
--------------------------------------------------------------------------------
- Method: DELETE /donation/delete-multiple
- Access: ADMIN, SUPER_ADMIN
- Headers: `Content-Type: application/json`
- Request Body:
  ```json
  {
    "ids": [
      "67cc1a2b3c4d5e6f7a8b9c01",
      "67cc2b3c4d5e6f7a8b9c02"
    ]
  }
  ```
- Response (200 OK):
  ```json
  {
    "statusCode": 200,
    "success": true,
    "message": "2 donation record(s) deleted successfully",
    "data": {
      "deletedCount": 2
    }
  }
  ```
