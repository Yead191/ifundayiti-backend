================================================================================
EXECUTIVE SUMMARY: HOW NOTIFICATIONS WORK
================================================================================
1. **Real-Time Push via Socket.io**:
   - Whenever an important platform event occurs (New Donation Received, Membership Activated, Grant Application Submitted, Order Created, Digital Product Purchased), the backend persists the notification to MongoDB AND immediately emits a socket event:
     `io.emit("getNotification::" + receiverUserId, notificationDoc)`
   - The frontend socket client listens on `getNotification::<currentUserId>`, shows an instant animated toast, and increments the unread badge count in real time without refreshing!
2. **REST API State Management**:
   - `GET /notification` — Fetches paginated notifications for the logged-in user + returns live `unreadCount`.
   - `PATCH /notification` — Marks ALL notifications as read (`seen: true`) in one click.
   - `PATCH /notification/:id` — Marks an individual notification as read.
   - `DELETE /notification/:id` — Deletes a single notification record.
   - `DELETE /notification/clear-all` — Clears all notification history for the current user.
   - `GET /notification/:id` — Fetches a single notification with populated sender details.
3. **Smart In-App Deep Linking**:
   - Every notification object has a `path` property (e.g. `"/donations"`, `"/orders"`, `"/transactions"`, `"/applications"`).
   - Clicking a notification automatically navigates the admin or user directly to the relevant resource!

--------------------------------------------------------------------------------
1. GET ALL NOTIFICATIONS (PAGINATED + UNREAD COUNT)
--------------------------------------------------------------------------------
- Method: GET /notification
- Access: Authenticated User (Admin, SuperAdmin, User, Vendor)
- Headers: `Authorization: Bearer <token>`

  - `limit`: number (default: 10)

6. SOCKET.IO REAL-TIME EVENT EXAMPLE (FRONTEND SETUP)
--------------------------------------------------------------------------------
```typescript
import { io, Socket } from "socket.io-client";
import { toast } from "sonner";

// Initialize socket
const socket: Socket = io("http://localhost:5000", {
  transports: ["websocket", "polling"],
});

// In React useEffect with current user ID:
useEffect(() => {
  if (!user?._id) return;

  const eventName = `getNotification::${user._id}`;

  socket.on(eventName, (newNotification: INotification) => {
    // 1. Play subtle audio chime (optional)
    // 2. Trigger notification toast
    toast(newNotification.title, {
      description: newNotification.message,
      action: {
        label: "View",
        onClick: () => navigate(newNotification.path),
      },
    });

    // 3. Invalidate RTK Query cache to fetch updated unreadCount & list
    dispatch(notificationApi.util.invalidateTags(["Notifications"]));
  });

  return () => {
    socket.off(eventName);
  };
}, [user?._id]);
```
