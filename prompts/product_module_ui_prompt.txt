================================================================================
IFUNDAYITI: APPAREL & CLOTHING MERCHANDISE STORE SPECIFICATION & PROMPT
================================================================================

--------------------------------------------------------------------------------
1. ARCHITECTURAL CONTEXT & MODULE OVERVIEW
--------------------------------------------------------------------------------
IFundAyiti's official apparel & clothing merchandise store sells high-quality,
ethically produced garments/clothing and accessories. 100% of store profits directly fund
community grants, solar power installations, and clean water projects in Haiti.

The platform is powered by two integrated modules:
1. CLOTHING CATEGORIES (/product-category):
   - Fast taxonomy (e.g., "Hoodies & Sweatshirts", "T-Shirts & Tops",
     "Caps & Headwear", "Outerwear & Jackets", "Activewear", "Accessories").
2. APPAREL PRODUCTS & INVENTORY MATRIX (/product):
   - Multi-image clothing showcase with dynamic Color + Size variant matrices,
     real-time stock tracking per SKU, pre-order capabilities with expected
     dispatch dates for backordered sizes, compare-at discount prices, gender
     classification (Men, Women, Unisex, Kids), tags, and sales analytics.

   - Endpoint: POST /product-category

5. DELETE CATEGORY:

2. STORE ANALYTICS & INVENTORY STATS (For Admin Dashboard):

   - Headers: Authorization: Bearer <ADMIN_TOKEN>
   - Response:

       "success": true,

       "data": {

       }
     }

3. GET SINGLE APPAREL PRODUCT:
   - Endpoint: GET /product/:id
   - Populates category and returns all size/color variants with stock status.

4. CREATE APPAREL PRODUCT:
   - Endpoint: POST /product
   - Headers: Authorization: Bearer <ADMIN_TOKEN>, Content-Type: multipart/form-data
   - Form-Data Fields:
     * `name` (string, e.g. "1804 Heritage Heavyweight Graphic Tee")
     * `description` (string, detailing fabric weight, fit, care instructions)
     * `category` (ObjectId string)
     * `price` (number, e.g. 35)
     * `compareAtPrice` (number, optional, e.g. 45 -> must be >= price)
     * `gender` (men | women | unisex | kids)
     * `status` (draft | active | inactive | archived)
     * `featured` (boolean)
     * `tags` (JSON array: `["tshirt", "graphic", "1804", "cotton"]`)
     * `variants` (JSON array of size/color SKUs):
       `[
         {"size": "S", "color": "Vintage Black", "stock": 20, "isPreOrder": false},
         {"size": "M", "color": "Vintage Black", "stock": 35, "isPreOrder": false},
         {"size": "L", "color": "Vintage Black", "stock": 0, "isPreOrder": true, "expectedAvailableDate": "2026-10-30"},
         {"size": "XL", "color": "Vintage Black", "stock": 15, "isPreOrder": false},
         {"size": "S", "color": "Palm Green", "stock": 10, "isPreOrder": false},
         {"size": "M", "color": "Palm Green", "stock": 22, "isPreOrder": false}
       ]`
     * `images` (Files: up to 10 photos of front, back, model shots, fabric close-up)

5. UPDATE APPAREL PRODUCT:
   - Endpoint: PATCH /product/:id
   - Headers: Authorization: Bearer <ADMIN_TOKEN>, Content-Type: multipart/form-data
   - Accepts any subset of fields + new image uploads.

6. QUICK STATUS TRANSITION:
   - Endpoint: PATCH /product/status/:id
   - Body: { "status": "active" | "draft" | "inactive" | "archived" }

7. TOGGLE FEATURED (SPOTLIGHT ON HOMEPAGE/STORE):
   - Endpoint: PATCH /product/featured/:id

8. SIZE & COLOR VARIANT INVENTORY CONTROL:
   - Set Specific Variant Stock:
     PATCH /product/variant-stock/:id
     Body: { "size": "L", "color": "Vintage Black", "stock": 50 }
   - Restock Variant (Add Quantity):
     PATCH /product/increase-stock/:id
     Body: { "size": "L", "color": "Vintage Black", "quantity": 25 }
   - Toggle Variant Pre-Order Mode:
     PATCH /product/pre-order/:id
     Body: {
       "size": "XL",
       "color": "Palm Green",
       "isPreOrder": true,
       "expectedAvailableDate": "2026-11-15"
     }

9. CHECK REAL-TIME VARIANT AVAILABILITY (Used by Storefront Cart):
   - Endpoint: GET /product/check-availability/:id?size=M&color=Vintage%20Black&quantity=2
   - Response:
     {
       "success": true,
       "data": {
         "available": true,
         "isPreOrder": false,
         "stock": 35,
         "expectedAvailableDate": null
       }
     }

10. DELETE PRODUCT:
    - Endpoint: DELETE /product/:id
    - Note: System protects products with sales history (`sold > 0`) from accidental deletion.

3. ADMIN DASHBOARD SPECIFICATION (Clothing & Inventory Management)
--------------------------------------------------------------------------------

A. REDUX API SLICES
   1. `src/redux/features/products/productsApi.ts`
      - Tags: `Products` (LIST, STATS, and specific IDs)
      - Endpoints for listing, filtering, create/update/delete, status transitions,
        and variant stock adjustments.
   2. `src/redux/features/categories/categoriesApi.ts`
      - Tags: `ProductCategories` (LIST)

B. APPAREL CATALOG MANAGEMENT PAGE (/dashboard/products)
   1. KPI Stat Cards:
      - Total Garments in Catalog
      - Active Live in Store
      - Total Inventory Stock across all Sizes/Colors
      - Out-of-Stock Variants Alert Badge (indicating sizes needing restock)
      - Total Units Sold
   2. Filter & Action Toolbar:
      - Live search (by product name, tags, or description)
      - Category Filter dropdown (Hoodies, T-Shirts, Headwear, etc.)
      - Gender Filter tabs (All, Men, Women, Unisex, Kids)
      - Status Tabs (`All`, `Active`, `Draft`, `Inactive`, `Archived`) with count badges
      - "+ Add Apparel Item" Primary Action CTA
      - "Manage Categories" Secondary CTA
   3. Data Table & Visual Grid View:
      - Columns:
        * Garment Thumbnail + Name + Gender Badge (e.g. [Unisex])
        * Category Badge (e.g. Hoodies)
        * Price & Compare-At (with discount % calculation)
        * Available Sizes & Colors Pill List (e.g. Sizes: S, M, L, XL | Colors: Navy, Black)
        * Inventory Units (with Low Stock / Pre-Order warnings)
        * Total Sold
        * Featured Spotlight toggle switch
        * Status Dropdown menu
        * Actions (Edit, Quick Stock Adjust, Delete)

C. CREATE & EDIT CLOTHING MODAL / DRAWER
   - Multi-step or multi-section form:
     1. Basic Info:
        - Product Title (e.g. "IFundAyiti French Terry Pullover Hoodie")
        - Category Dropdown (populated from /product-category)
        - Gender Select: [Men, Women, Unisex, Kids]
        - Tags (Input tags: "fleece", "hoodie", "organic", "1804")
        - Detailed Garment Description (Fabric composition, GSM weight, fit type, wash care)
     2. Pricing & Publishing:
        - Retail Price ($)
        - Compare-at Price ($) (for sales/discount badge)
        - Status (Draft / Active / Inactive / Archived)
        - Feature on Homepage (Toggle)
     3. Media Gallery Upload:
        - Drag-and-drop dropzone for up to 10 high-res photos (Front, Back, Model, Fabric close-up)
        - Image preview grid with remove buttons.
     4. Dynamic Variant & Inventory Matrix Builder:
        - Interactive table with quick preset buttons:
          * Size Presets: "+ Standard Sizes (S, M, L, XL, XXL)"
          * Color Input: Name (e.g. "Caribbean Navy", "Oatmeal", "Crimson") + optional Hex Color Swatch
        - Each Variant Row includes:
          * Size (S, M, L, XL, etc.)
          * Color Name (Navy, Black, etc.)
          * Stock Quantity (Number, min: 0)
          * Pre-Order Checkbox ("Accept orders when out of stock")
          * Expected Available Date (DatePicker, enabled only if Pre-Order is checked)
          * Delete row button

D. QUICK VARIANT RESTOCK MODAL (/dashboard/products -> Restock)
   - Allows warehouse admins to select a garment, choose Color and Size from a dropdown,
     and instantly add +X units to stock without opening the full edit form.
