================================================================================
EXECUTIVE SUMMARY: WHAT THE BACKEND PROVIDES
================================================================================
1. **Live User Analytics & KPI Metrics (`GET /user/stats`)**:
   - Returns real-time aggregate counts:
     • `totalUsers` — Total platform accounts (excluding SUPER_ADMIN)
     • `activeUsers` — Active accounts
     • `blockedUsers` — Blocked / deactivated accounts
     • `pendingUsers` — Pending review / approval
     • `verifiedUsers` & `unverifiedUsers` — Email verification status breakdown
     • `regularUsers` (`USER`) — Standard platform members / donors
     • `vendors` (`VENDOR`) — Service providers / campaign creators
     • `admins` (`ADMIN`) — Dashboard staff / admins
     • `newThisMonth` — User registrations in the current month

2. **Advanced Paginated Listing & Search (`GET /user`)**:
   - Search: Across `name`, `email`, and `company` (`?searchTerm=john`)
   - Role Filter: `?role=USER`, `?role=VENDOR`, `?role=ADMIN`, or `?role=all`
   - Status Filter: `?status=active`, `?status=blocked`, `?status=pending`, `?status=rejected`
   - Verified Filter: `?verified=true` or `?verified=false`
   - Subscription Filter: `?hasSubscription=true` or `?hasSubscription=false`
   - Pagination: `?page=1&limit=10`
   - Sorting: `?sort=-createdAt` or `?sort=name`
   - Automatically populates user `subscription` details and sanitizes sensitive fields.

3. **Single User Inspector / Profile Modal (`GET /user/:id`)**:
   - Returns complete user record including role, verified status, company, interest, vendor profile, subscription, timestamps, and avatar.

4. **Instant Status Toggling & Block/Unblock (`PATCH /user/change-status/:id`)**:
   - Toggles status between `active` and `blocked` if no body is passed.
   - Or explicitly sets `{ status: "blocked" | "active" | "pending" | "rejected", rejectionReason?: string }`.

5. **Admin User Update & Role Assignment (`PATCH /user/:id`)**:
   - Updates `role`, `status`, `name`, `email`, `verified`, `company`, `interest`, or `rejectionReason`.

6. **Single & Batch Deletion (`DELETE /user/:id` & `DELETE /user/delete-multiple`)**:
   - Cleanly deletes records and safely unlinks local avatar files.

  - `page` (number): Default `1`
  - `limit` (number): Default `10`
  - `sort` (string): e.g. `-createdAt` or `name`

File: `src/redux/features/user/userApi.ts`

```typescript
import { baseApi } from '../../api/baseApi';

export interface IUserStats {
  totalUsers: number;
  activeUsers: number;
  blockedUsers: number;
  pendingUsers: number;
  verifiedUsers: number;
  unverifiedUsers: number;
  regularUsers: number;
  vendors: number;
  admins: number;
  newThisMonth: number;
}

export interface IUser {
  _id: string;
  name: string;
  email: string;
  role: 'SUPER_ADMIN' | 'ADMIN' | 'USER' | 'VENDOR';
  image?: string;
  status: 'active' | 'blocked' | 'pending' | 'rejected';
  rejectionReason?: string;
  verified: boolean;
  company?: string;
  interest?: string;
  subscription?: any;
  vendorProfile?: any;
  createdAt: string;
  updatedAt: string;
}

export const userApi = baseApi.injectEndpoints({
  endpoints: (builder) => ({
    getUserStats: builder.query<{ success: boolean; data: IUserStats }, void>({
      query: () => ({
        url: '/user/stats',
        method: 'GET',
      }),
      providesTags: ['Users'],
    }),

    getAllUsers: builder.query<{ success: boolean; data: IUser[]; pagination: any }, Record<string, any>>({
      query: (params) => ({
        url: '/user',
        method: 'GET',
        params,
      }),
      providesTags: ['Users'],
    }),

    getSingleUser: builder.query<{ success: boolean; data: IUser }, string>({
      query: (id) => ({
        url: `/user/${id}`,
        method: 'GET',
      }),
      providesTags: (result, error, id) => [{ type: 'Users', id }],
    }),

    changeUserStatus: builder.mutation<
      { success: boolean; data: IUser },
      { id: string; status?: string; rejectionReason?: string }
    >({
      query: ({ id, ...body }) => ({
        url: `/user/change-status/${id}`,
        method: 'PATCH',
        body,
      }),
      invalidatesTags: ['Users'],
    }),

    updateUserByAdmin: builder.mutation<
      { success: boolean; data: IUser },
      { id: string; data: Partial<IUser> }
    >({
      query: ({ id, data }) => ({
        url: `/user/${id}`,
        method: 'PATCH',
        body: data,
      }),
      invalidatesTags: ['Users'],
    }),

    deleteUser: builder.mutation<{ success: boolean; data: any }, string>({
      query: (id) => ({
        url: `/user/${id}`,
        method: 'DELETE',
      }),
      invalidatesTags: ['Users'],
    }),

    deleteMultipleUsers: builder.mutation<{ success: boolean; data: { deletedCount: number } }, string[]>({
      query: (ids) => ({
        url: '/user/delete-multiple',
        method: 'DELETE',
        body: { ids },
      }),
      invalidatesTags: ['Users'],
    }),
  }),
});

export const {
  useGetUserStatsQuery,
  useGetAllUsersQuery,
  useGetSingleUserQuery,
  useChangeUserStatusMutation,
  useUpdateUserByAdminMutation,
  useDeleteUserMutation,
  useDeleteMultipleUsersMutation,
} = userApi;
```
