PART 3: BACKEND API CHEAT SHEET & DATA CONTRACTS
================================================================================

--------------------------------------------------------------------------------
A. BLOG CATEGORY API ENDPOINTS
--------------------------------------------------------------------------------

1. GET ALL CATEGORIES
   - URL: `GET /blog-category` or `GET /blogcategory`
   - Access: Public
   - Query: `searchTerm`, `sort` (default: 'name')
   - Response:
     ```json
     {
       "statusCode": 200,
       "success": true,
       "message": "Blog categories fetched successfully",
       "data": [
         {
           "_id": "67cb1a2b3c4d5e6f7a8b9c01",
           "name": "Community Impact",
           "slug": "community-impact",
           "blogCount": 8,
           "createdAt": "2026-08-15T10:00:00.000Z",
           "updatedAt": "2026-08-15T10:00:00.000Z"
         }
       ]
     }
     ```

2. GET SINGLE CATEGORY
   - URL: `GET /blog-category/:idOrSlug`
   - Access: Public
   - Response: Category object with `blogCount`.

3. CREATE CATEGORY
   - URL: `POST /blog-category`
   - Access: Admin, SuperAdmin (Bearer Token)
   - Headers: `Content-Type: application/json`
   - Body:
     ```json
     {
       "name": "Healthcare Initiatives"
     }
     ```
   - Response: 201 Created (Auto-generates unique slug).

4. UPDATE CATEGORY
   - URL: `PATCH /blog-category/:id`
   - Access: Admin, SuperAdmin
   - Body: `{ "name": "Updated Category Name" }`
   - Response: 200 OK (Regenerates slug if name is changed).

5. DELETE CATEGORY
   - URL: `DELETE /blog-category/:id`
   - Access: Admin, SuperAdmin
   - Response: 200 OK.
   - Note: Safely prevented if any blogs are linked to this category.

--------------------------------------------------------------------------------
B. BLOG POSTS API ENDPOINTS
--------------------------------------------------------------------------------

1. GET ALL BLOGS
   - URL: `GET /blog` or `GET /blogs`
   - Access: Public (Public gets only `published`; Admins get `draft`, `published`, `archived`)
   - Query Parameters:
     - `page`: number (default: 1)
     - `limit`: number (default: 10)
     - `searchTerm`: string (searches in `title` and `content`)
     - `category`: string (Category ObjectId or category slug)
     - `status`: "published" | "draft" | "archived" (Admin only)
     - `isFeatured`: boolean
     - `sort`: string (default: "-publishedAt -createdAt")
   - Response:
     ```json
     {
       "statusCode": 200,
       "success": true,
       "message": "Blogs fetched successfully",
       "pagination": { "page": 1, "limit": 10, "total": 24, "totalPage": 3 },
       "data": [
         {
           "_id": "67cb2b3c4d5e6f7a8b9c02",
           "title": "Empowering Local Farmers in Artibonite",
           "slug": "empowering-local-farmers-in-artibonite",
           "content": "<p>Detailed story HTML or Markdown content...</p>",
           "image": "/image/farmers-17890123.jpg",
           "category": {
             "_id": "67cb1a...",
             "name": "Agriculture & Food",
             "slug": "agriculture-food"
           },
           "author": {
             "_id": "67cb0a...",
             "name": "Jean-Pierre Duval",
             "email": "jp@ifundayiti.org",
             "image": "/image/avatar-12.jpg"
           },
           "tags": ["Agriculture", "Micro-grants", "Artibonite"],
           "status": "published",
           "isFeatured": true,
           "publishedAt": "2026-08-20T14:30:00.000Z",
           "createdAt": "2026-08-20T12:00:00.000Z"
         }
       ]
     }
     ```

2. GET SINGLE BLOG
   - URL: `GET /blog/:idOrSlug`
   - Access: Public (Accepts either ObjectId or unique slug!)
   - Public visitors receive 404 if post is in `draft` or `archived` status.
   - Admins can preview any post status.

3. CREATE BLOG
   - URL: `POST /blog`
   - Access: Admin, SuperAdmin
   - Content-Type: `multipart/form-data`
   - Form Fields:
     - `title`: string (Required)
     - `content`: string (Required, rich text HTML)
     - `category`: string (Required, Category ObjectId)
     - `image`: File (Optional cover photo)
     - `tags`: string[] or comma-separated string (Optional)
     - `status`: "draft" | "published" | "archived" (Optional, default: "draft")
     - `isFeatured`: boolean (Optional, default: false)
     - `author`: string (Optional - automatically set to current admin's User ID if omitted)
   - Response: 201 Created

4. UPDATE BLOG
   - URL: `PATCH /blog/:id`
   - Access: Admin, SuperAdmin
   - Content-Type: `multipart/form-data`
   - Form Fields: Any fields to update. If a new `image` is uploaded, old file is purged from disk.
   - Response: 200 OK

5. QUICK UPDATE STATUS
   - URL: `PATCH /blog/status/:id`
   - Access: Admin, SuperAdmin
   - Headers: `Content-Type: application/json`
   - Body: `{ "status": "published" }` ("published" | "draft" | "archived")
   - Response: 200 OK (Automatically sets `publishedAt = new Date()` on first publish)

6. QUICK TOGGLE FEATURED
   - URL: `PATCH /blog/featured/:id`
   - Access: Admin, SuperAdmin
   - Headers: `Content-Type: application/json`
   - Body: `{}`
   - Response: 200 OK (Toggles boolean flag)

7. GET STATS
   - URL: `GET /blog/stats`
   - Access: Admin, SuperAdmin
   - Response: `{ statusCode: 200, success: true, data: { total: 24, published: 18, draft: 4, archived: 2, featured: 5 } }`

8. DELETE BLOG
   - URL: `DELETE /blog/:id`
   - Access: Admin, SuperAdmin
   - Response: 200 OK (Unlinks physical cover photo from disk and removes database entry)

PART 4: TYPESCRIPT DATA MODELS
================================================================================

```typescript
export const BLOG_STATUS = {
  DRAFT: 'draft',
  PUBLISHED: 'published',
  ARCHIVED: 'archived',
} as const;

export type BLOG_STATUS = (typeof BLOG_STATUS)[keyof typeof BLOG_STATUS];

export interface IBlogCategory {
  _id: string;
  name: string;
  slug: string;
  blogCount?: number;
  createdAt: string;
  updatedAt: string;
}

export interface IBlog {
  _id: string;
  title: string;
  slug: string;
  content: string;
  image?: string;
  category: {
    _id: string;
    name: string;
    slug: string;
  } | string;
  author: {
    _id: string;
    name: string;
    email: string;
    image?: string;
  } | string;
  tags?: string[];
  status: BLOG_STATUS;
  isFeatured: boolean;
  publishedAt?: string;
  createdAt: string;
  updatedAt: string;
}

export interface IBlogStats {
  total: number;
  published: number;
  draft: number;
  archived: number;
  featured: number;
}
```
